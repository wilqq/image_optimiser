# Layout Components

Components that define the layout structure of pages.

## Guidelines

- Header, Footer, Navigation, Sidebar
- Page wrappers and containers
- Responsive layout logic
- Shared across multiple pages

## Example Components

- `Header.tsx` - Top navigation and branding
- `Footer.tsx` - Site footer
- `Sidebar.tsx` - Side navigation
- `Container.tsx` - Content wrapper with max-width
- `MainLayout.tsx` - Main app layout structure
